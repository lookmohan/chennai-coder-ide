# Brand

Logo: `frontend/public/logo.svg`, a dot-grid "C" fading from deep navy (left) to cyan (right). The mark has no wordmark; pair it with "Chennai Coder" set in the UI font.

## Palette (sampled from the logo)

| Token | Hex | Use |
|---|---|---|
| navy-900 | `#00106E` | Dark surfaces, deepest accent |
| navy-700 | `#0A2A9E` | Headings on light, dark-mode borders |
| blue-600 | `#1160F8` | **Primary** buttons, links, focus ring |
| sky-500 | `#0088F8` | Secondary accent, charts |
| sky-400 | `#00B4FF` | Charts, highlights |
| cyan-300 | `#00ECFC` | Sparing accent (streaks, success glints) |

Guidance: keep UI mostly neutral (slate greys); use `blue-600` as the single primary. Use the cyan end of the gradient sparingly, never as large flat backgrounds, and check text contrast (white on `#1160F8` passes AA for normal text; cyan text on white does not).
